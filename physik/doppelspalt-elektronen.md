# Physik LK – Interferenz am Doppelspalt (a–d) + Elektronenbeugung

Aufgabe „Interferenz am Doppelspalt (überarbeitet)“, Erwartungshorizont für b/c lag bei. Bearbeitet 04.11.2026, Handschrift als GoodNotes/PDF (3 Karo-Seiten, Skizzen zu a und c).
Daten: λ = 633 nm, g = 0,25 mm, e = 1,20 m.

## a) Entstehung + Winkel 3. Ordnung
- Huygens: jeder Spalt sendet eine Elementarwelle aus → Überlagerung (Interferenz).
- Gangunterschied zu einem Punkt P: **Δs = g·sin α** (Skizze: rechtwinkliges Dreieck mit Hypotenuse g).
- Δs = k·λ → Maximum (hell), Δs = (2k+1)·λ/2 → Minimum (dunkel) → helle und dunkle Streifen, symmetrisch, Mitte hell.
- g·sin α_k = k·λ (FS) → sin α₃ = 3·633·10⁻⁹ / 0,25·10⁻³ = 7,60·10⁻³ → **α₃ ≈ 0,435°**
- (Ort: a₃ = e·tan α₃ ≈ 9,1 mm)

## b) Zuordnung (wie Erwartungshorizont)
| Muster | Anordnung | Begründung |
|---|---|---|
| 1 | Gitter | sehr schmale, scharfe Hauptmaxima, dazwischen fast nichts → sehr großes N |
| 2 | Einzelspalt | ein breites Hauptmaximum, schwache Nebenmaxima, anderer Maßstab (±0,10 m) |
| 3 | Vierfachspalt | Hauptmaxima wie Muster 1, dazwischen 2 Nebenmaxima / 3 Minima → N − 2 = 2 → N = 4 |
| – | Doppelspalt | fehlt; N = 2 → keine Nebenmaxima |

## c) Skizze Doppelspalt
- Hauptmaxima bei 0 und ±0,05 m (gleiches g wie Muster 3 → gleiche Lage, g·sin α = k·λ)
- alle gleich hoch (1,0), Einzelspalteinfluss vernachlässigt
- keine Nebenmaxima, je ein Minimum mittig (±0,025 m, Δs = λ/2)
- breite, cos²-förmige Maxima (je weniger Spalte, desto breiter)

## d) Elektronen als Welle
- **Experiment:** Elektronenbeugungsröhre – Glühkathode, Beschleunigungsspannung U, polykristalline Graphitfolie, Leuchtschirm → konzentrische Ringe (Interferenz an den Kristallgittern); U größer → λ kleiner → Ringe kleiner. (Alternative: Jönsson-Doppelspaltversuch mit Elektronen.)
- **Herleitung:** λ = h/p (de Broglie, FS), p = m·v → **v = h/(m·λ)**
- **Rechnung:** v = 6,626·10⁻³⁴ / (9,109·10⁻³¹ · 1,21·10⁻¹¹) ≈ **6,01·10⁷ m/s ≈ 0,20·c**
- relativistisch exakt: v ≈ 5,89·10⁷ m/s (≈ 0,197·c) → klassisch ca. 2 % zu hoch; nötige Spannung ≈ 10 kV.

## Klausurfertige Kurzversion
- Δs = g·sin α; hell bei Δs = kλ → α₃ = arcsin(3λ/g) ≈ 0,435°.
- Muster: N − 2 Nebenmaxima → 1 Gitter, 2 Einzelspalt, 3 Vierfachspalt, Doppelspalt fehlt.
- Doppelspalt: breite gleich hohe Maxima, keine Nebenmaxima.
- Elektronen: Beugungsringe; v = h/(mλ) ≈ 6,0·10⁷ m/s ≈ 20 % von c.
