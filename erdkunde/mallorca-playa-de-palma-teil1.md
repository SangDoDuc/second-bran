# Erdkunde LK – Scheitert Mallorcas touristische Qualitätsoffensive? Teil 1: Das touristische Potenzial

Material: M1 Playa de Palma/S'Arenal 1960 und heute, M2 Bevölkerungsentwicklung (beide Grün, U. (2023): Die Rückkehr des Ballermanns. Praxis Geographie 4: 27–31) · Diercke-Atlas, Karte „Mallorca – Tourismus“.

> Abgelesene/gezählte Werte sind mit „ca.“ markiert: Hotelkomplexe in M1 gezählt (1960: 3, heute über 50); Atlas-Diagramm „Herkunft der Urlaubsreisenden“ nur grob abgelesen (Deutschland vorn, ca. 4–4,5 Mio. Gäste/Jahr vor 2020, Einbruch 2020).

## 1 Lokalisierung (vom Großen ins Kleine)

- Südeuropa → westliches Mittelmeer → Spanien → Balearen → **Mallorca** (Hauptinsel), rund 200 km vor der spanischen Ostküste
- Südküste Mallorcas, **Bucht von Palma**
- ca. 15 km östlich vom Zentrum Palmas, 5 km vom Flughafen (M1)
- 4,5 km langer Strand von Can Pastilla bis S'Arenal, in 15 Balnearios gegliedert
- ca. 39,5° N / 2,7° O

## 2 Touristisches Potenzial (Operator „erläutern“: Faktor + Begründung, warum touristisch nutzbar)

| | Faktor | Warum Potenzial |
|---|---|---|
| **natürlich (ursprünglich)** | 4,5 km flacher Sandstrand in geschützter Bucht | Badeurlaub, familien- und massentauglich |
| | Mittelmeerklima (warm-trockene Sommer, milde Winter) | lange Badesaison, Sonnengarantie |
| | Wald/Park im Hinterland | Erholung, Grün |
| **abgeleitet (anthropogen)** | Flughafen 5 km, Autobahn | kurze Transfers, Charter- und Billigflüge → Kurzurlaube möglich |
| | Palma 15 km | Kultur, Altstadt, Shopping als Ausflug |
| | viele Hotelkomplexe (≥ 300 Betten), Tourismuszone | sehr hohe Bettenkapazität → Pauschal-/Massentourismus |
| | Sporthafen, Aqualand, 15 Strandbars | Freizeitangebot |
| | Partymeile (Bierstraße, Schinkenstraße, Balneario 6, Oberbayern, Megapark), Marke „Ballermann“ seit den 1970ern | starkes Image/Bekanntheit bei deutschen Partytouristen |
| | Franziskanerkirche, Museum | etwas Kultur vor Ort |

**Fazit:** sehr hohes Potenzial für Bade- und Massentourismus, aber einseitig auf billigen Partytourismus ausgerichtet → schwierige Ausgangslage für eine Qualitätsoffensive.

## 3 Veränderungen durch den Massentourismus seit 1960 (Operator „charakterisieren“: typische Merkmale herausarbeiten und einordnen)

| Bereich | 1960 | heute | Charakter |
|---|---|---|---|
| Flächennutzung | v. a. Landwirtschaft, Wald/Strauchland, kleine Siedlungen (Las Maravillas, S'Arenal) | fast vollständig bebaut: Wohngebiete, Hotels, Gewerbe | Verstädterung, Zersiedlung, Versiegelung, Verlust der Landwirtschaft |
| Tourismus | 3 Hotelkomplexe | über 50 (gezählt), durchgehende Tourismuszone am Strand, Partymeile, Sporthafen, Aqualand | Massentourismus, touristische Monostruktur |
| Gewerbe | kleine Gewerbeflächen | stark ausgeweitet (östlich, Ses Cadenes) | Funktionswandel zum Dienstleistungsraum |
| Verkehr | Eisenbahn | Eisenbahn weg, Autobahn + dichteres Straßennetz | Ausrichtung auf Flughafen und Pkw/Bus |
| Bevölkerung (M2) | S'Arenal 1 162, Palma 157 100 | S'Arenal 16 500 (2022), Palma 416 000 | S'Arenal ×14 (stärkstes Wachstum 1960–1980: ×7,8), Palma nur ×2,6 → Tourismus als Pull-Faktor |
| Atlas | – | Küste der Bucht von Palma fast durchgehend Siedlungsfläche, Seebäder neben dem Flughafen; Gäste v. a. aus Deutschland | Teil einer verstädterten Tourismusküste |

**Gesamt:** Aus einem ländlichen Küstenraum ist ein verstädterter, einseitig auf Massen- und Partytourismus ausgerichteter Raum geworden.

## Warum so – was bringt Punkte – typische Fehler

| Aufgabe | Was Punkte bringt | Typische Fehler |
|---|---|---|
| 1 Lokalisieren | groß → klein, Lagebegriffe (Bucht, Balearen), Entfernungen aus M1 | nur „auf Mallorca“ |
| 2 Erläutern | Trennung natürlich/abgeleitet, **jeweils Begründung**, Fazit mit Bezug zur Qualitätsoffensive | nur aufzählen ohne „→ warum“ |
| 3 Charakterisieren | Vergleich 1960 ↔ heute **mit Werten** (M2 rechnen: ×14 vs. ×2,6), Fachbegriffe (Verstädterung, Versiegelung, Monostruktur), Gesamturteil | nur M1 beschreiben, M2/Atlas vergessen; keine Einordnung |

## Klausurfertige Kurzversion

- **Lage:** Mallorca (Balearen, Spanien), Bucht von Palma, 15 km östl. Palma, 5 km Flughafen, 4,5 km Strand bis S'Arenal.
- **Potenzial:** natürlich = Strand + Mittelmeerklima; abgeleitet = Flughafen/Autobahn, Bettenkapazität, Partymeile/„Ballermann“-Image, Nähe Palma → hoch, aber einseitig (Partytourismus).
- **Wandel seit 1960:** Landwirtschaft → Bebauung (Verstädterung, Versiegelung); 3 → über 50 Hotelkomplexe; Bahn weg, Autobahn da; S'Arenal ×14 (1 162 → 16 500) vs. Palma ×2,6 → touristische Monostruktur.
