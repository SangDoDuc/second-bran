# Comment (Stellungnahme)

1. Kurze Positionierung (zustimmen / teilweise / nein)
2. Argumente pro – jeweils Begründung **+ konkretes Beispiel**
3. Gegenargumente (bringt fast immer Extrapunkte)
4. Fazit mit klarer Position
- Mindestens **ein Punkt, der nicht im Text steht** – sonst ist es nur eine zweite Zusammenfassung.
