## 1. Aufbau der Gedichtanalyse

| Teil | Inhalt |
|---|---|
| **Einleitung** | Titel, Autor, Erscheinungsjahr, Epoche, Thema + **Deutungshypothese** (1–2 Sätze: Was will das Gedicht zeigen?) |
| **Hauptteil 1: Inhalt** | kurz, Strophe für Strophe, **im Präsens**, nicht nacherzählen, sondern zusammenfassen |
| **Hauptteil 2: Form** | Strophen, Verse, Reimschema, Metrum, Kadenzen, Zeilenstil/Enjambement → **und was die Form bewirkt** |
| **Hauptteil 3: Sprache** | Stilmittel mit **Name → Zitat (V. x) → Wirkung**. Das Wichtigste zuerst. |
| **Hauptteil 4: Epochenbezug** | Welche Merkmale des Expressionismus zeigt das Gedicht? |
| **Schluss** | Hypothese bestätigen, Hauptaussage in 2–3 Sätzen, eventuell Aktualität oder eigene Wirkung |

**Einleitungs-Schablone:**
> Das Gedicht „[Titel]“ von [Autor] wurde [Jahr] veröffentlicht und lässt sich der Epoche des Expressionismus zuordnen. Es handelt von [Thema, z. B. der Großstadt / dem Weltende / dem Krieg]. Das lyrische Ich zeigt [Haltung, z. B. Angst / Entfremdung]. Es lässt sich vermuten, dass das Gedicht [Deutungshypothese, z. B. die Entmenschlichung des Menschen in der Großstadt kritisiert].

**Wichtig:** Immer **„das lyrische Ich“**, nie „der Autor sagt“. Keine Stimme im Gedicht? Dann „der Sprecher“ oder „es wird beschrieben“.

## 2. Form – die Begriffe

| Begriff | Bedeutung | typische Wirkung |
|---|---|---|
| **Strophe / Vers** | Absatz / Zeile | Anzahl nennen: „4 Strophen mit je 4 Versen“ |
| **Paarreim** aabb | | schlicht, eingängig |
| **Kreuzreim** abab | | Ordnung, Fluss |
| **umarmender Reim** abba | | geschlossen, eingeschlossen |
| **kein Reim** / freie Verse | | Auflösung, Chaos |
| **Jambus** xX | unbetont–betont („Ge**dicht**“) | ruhig, gleichmäßig, oft **5-hebig** im Expressionismus |
| **Trochäus** Xx | betont–unbetont („**Son**ne“) | schwer, drängend |
| **Daktylus** Xxx | („**Kö**nigin“) | tänzerisch, bewegt |
| **männliche Kadenz** (stumpf) | Vers endet **betont** („Hut“) | hart, abgehackt |
| **weibliche Kadenz** (klingend) | Vers endet **unbetont** („**hup**fen“) | weich, offen |
| **Zeilenstil** | Satz endet mit dem Vers | Abgehacktes, Nebeneinander |
| **Enjambement** | Satz geht über das Versende hinaus | Bewegung, Unruhe, Hervorhebung |
| **Sonett** | 14 Verse: 2 Quartette (4) + 2 Terzette (3) | im Expressionismus oft: **strenge Form vs. chaotischer Inhalt** |
| **Reihungsstil / Simultanstil** | Bilder werden ohne Zusammenhang aneinandergereiht | Gleichzeitigkeit, Chaos der Großstadt, Zerfall der Welt |

**Metrum bestimmen (Trick):** Vers leise sprechen, Betonungen markieren. Wechseln sich unbetont–betont ab, ist es ein Jambus. Hebungen zählen → „fünfhebiger Jambus“. Wenn es unregelmäßig ist, einfach schreiben: „kein durchgehendes Metrum → wirkt unruhig“. Das ist auch eine Aussage.

**Satz für die Form:** *„Die strenge, regelmäßige Form steht im Gegensatz zum chaotischen Inhalt. Dadurch wirkt der Zerfall der Welt noch erschreckender.“* Passt bei fast jedem expressionistischen Gedicht.

## 3. Die wichtigsten Stilmittel (schnell zu merken)

| Stilmittel | Erklärung | Beispiel | typische Wirkung |
|---|---|---|---|
| **Metapher** | Bild ohne „wie“ | „das Meer der Häuser“ | verdichtet, macht anschaulich |
| **Vergleich** | Bild mit „wie“ | „wie Geschrei“ | veranschaulicht |
| **Personifikation** | Dinge handeln wie Menschen | „die wilden Meere hupfen“ | Dinge wirken lebendig, oft **bedrohlich** |
| **Verdinglichung** | Menschen wirken wie Dinge | „Dachdecker … gehn entzwei“ | **Entmenschlichung** (sehr expressionistisch) |
| **Farbsymbolik** | Farben mit Bedeutung | rot = Blut, Gewalt · schwarz = Tod · grau = Trostlosigkeit | Stimmung, Ausdruck statt Abbild |
| **Aufzählung / Reihung** | viele Dinge nacheinander | | Hektik, Chaos, Überforderung |
| **Anapher** | gleicher Versanfang | „Die … / Die …“ | Eindringlichkeit, Monotonie |
| **Wiederholung** | | | Betonung, Eintönigkeit |
| **Alliteration** | gleicher Anlaut | „dicke Dämme“ | Klang, Betonung |
| **Antithese** | Gegensatz | Leben – Tod | Spannung, Zerrissenheit |
| **Oxymoron** | Widerspruch in einem Ausdruck | „süßer Schmerz“ | Paradoxie, Zerrissenheit |
| **Hyperbel** | Übertreibung | | Dramatik |
| **Ellipse** | unvollständiger Satz | | Atemlosigkeit, Zerfall der Sprache |
| **Neologismus** | Wortneuschöpfung | | Bruch mit der Sprache, Neues ausdrücken |
| **Synästhesie** | Sinne vermischt | „grelles Geschrei“ | intensive, verwirrte Wahrnehmung |
| **Lautmalerei** | Klang ahmt Geräusch nach | „zischen“, „dröhnen“ | Lärm der Großstadt hörbar |
| **Klimax** | Steigerung | | Spannung, Höhepunkt |
| **Inversion** | ungewöhnliche Wortstellung | | Hervorhebung |
| **Chiffre** | rätselhaftes, eigenes Bild (Trakl) | | Geheimnis, Untergangsstimmung |
| **Ironie / Groteske** | Schreckliches neben Banalem | Weltende neben „Schnupfen“ | Absurdität, Kritik am Bürgertum |

**So schreibst du es (Name → Zitat → Wirkung):**
> *Im fünften Vers wird eine Personifikation verwendet („die wilden Meere hupfen“, V. 5). Die Natur wirkt dadurch lebendig und unberechenbar. So entsteht der Eindruck, dass der Mensch die Kontrolle über die Welt verloren hat.*

Merke: **Ein Stilmittel ohne Wirkung bringt fast keine Punkte.** Lieber 5 Stilmittel mit Wirkung als 12 ohne.

## 4. Expressionismus – das Wichtigste

| Was | Inhalt |
|---|---|
| **Zeit** | ca. **1910–1920**, endet mit dem Ersten Weltkrieg und danach |
| **Name** | *expressio* = Ausdruck: **Ausdruck des Inneren statt Abbild der Wirklichkeit** |
| **Hintergrund** | Industrialisierung, schnell wachsende **Großstädte** (Berlin), Technik, Lärm, Masse, **Anonymität**; Kritik am **Bürgertum** und den Werten der Väter; Gottesverlust (Nietzsche), Sinnverlust; Vorahnung und Erfahrung des **Ersten Weltkriegs** (1914–1918) |
| **Themen** | **Großstadt** (fasziniert und bedroht) · **Weltende / Apokalypse** · **Krieg** · **Ich-Zerfall**, Einsamkeit, Wahnsinn · Krankheit, Tod, **Hässliches** · Aufbruch, **„neuer Mensch“** |
| **Merkmale der Sprache** | Reihungsstil, starke Bilder und Farben, Personifikation von Stadt und Dingen (Dämonisierung), Verdinglichung des Menschen, Ellipsen, Neologismen, Ausrufe, „Ästhetik des Hässlichen“ |
| **Form** | Zerstörung der Form **oder** bewusst strenge Form (Sonett) als Kontrast zum Chaos |
| **Autoren + Gedichte** | Jakob van Hoddis „Weltende“ (1911) · Georg Heym „Der Gott der Stadt“ · Alfred Lichtenstein „Die Dämmerung“ · Georg Trakl „Grodek“ · Gottfried Benn „Kleine Aster“ · Paul Zech „Fabrikstraße tags“ · Ernst Stadler · August Stramm · Else Lasker-Schüler |
| **Vorher / nachher** | Naturalismus (Wirklichkeit genau abbilden) → **Expressionismus (Inneres ausdrücken)** → Neue Sachlichkeit (nüchtern, sachlich) |

**Epochenbezug-Satz:**
> *Das Gedicht ist typisch für den Expressionismus, weil es [Thema, z. B. die Großstadt als bedrohlich] darstellt und dabei [Merkmal, z. B. den Reihungsstil und die Verdinglichung des Menschen] verwendet. Damit spiegelt es die Verunsicherung der Menschen zu Beginn des 20. Jahrhunderts wider.*

## 5. Mögliche Aufgabenstellungen

| Aufgabe | Was du tust |
|---|---|
| „**Analysieren** Sie das Gedicht …“ | komplette Analyse: Einleitung → Inhalt → Form → Sprache → Schluss |

| „**Erörtern / Nehmen Sie Stellung**“ | eigene Meinung mit Argumenten und Beispiel, klares Fazit |

## 6. Musterbeispiel: Jakob van Hoddis, „Weltende“ (1911)

> Dem Bürger fliegt vom spitzen Kopf der Hut,
> In allen Lüften hallt es wie Geschrei.
> Dachdecker stürzen ab und gehn entzwei
> Und an den Küsten – liest man – steigt die Flut.
>
> Der Sturm ist da, die wilden Meere hupfen
> An Land, um dicke Dämme zu zerdrücken.
> Die meisten Menschen haben einen Schnupfen.
> Die Eisenbahnen fallen von den Brücken.

| Bereich | Analyse |
|---|---|
| **Form** | 2 Strophen à 4 Verse, 1. Strophe umarmender Reim (abba), 2. Strophe Kreuzreim (cdcd), **fünfhebiger Jambus** → ordentliche Form gegen chaotischen Inhalt |
| **Reihungsstil** | jeder Vers ein eigenes Bild, kaum Zusammenhang (**Zeilenstil**) → Simultaneität, Welt zerfällt in Einzelteile |
| **Verdinglichung** | „Dachdecker … gehn entzwei“ (V. 3) → Menschen zerbrechen wie Gegenstände, **Entmenschlichung** |
| **Personifikation** | „die wilden Meere hupfen“ (V. 5) → Natur wird lebendig und bedrohlich |
| **Groteske / Ironie** | Weltuntergang neben „Die meisten Menschen haben einen Schnupfen“ (V. 7) → absurd, Banales und Katastrophe gleichwertig |
| **„liest man“** | (V. 4) → Katastrophe nur aus der Zeitung, Distanz und Gleichgültigkeit |
| **Bürgerkritik** | „Dem Bürger fliegt vom spitzen Kopf der Hut“ (V. 1) → der Bürger wird lächerlich gemacht |
| **Deutung** | Weltende-Stimmung vor dem Ersten Weltkrieg, Kritik an einer gleichgültigen, bürgerlichen Gesellschaft |

## 7. Typische Fehler (vermeiden!)

- Inhalt **nacherzählen** statt deuten
- Stilmittel nennen **ohne Wirkung**
- **Autor = lyrisches Ich** setzen
- Zitate **ohne Versangabe** → immer „(V. 3)“
- **Vergangenheit** statt **Präsens**
- keine **Deutungshypothese** in der Einleitung
- Epochenmerkmale nur aufzählen, **ohne Beleg** im Gedicht
- Form beschreiben, aber nicht sagen, **was sie bewirkt**

## 8. Kurzversion (morgens lesen)

1. **Aufbau:** Einleitung (Titel, Autor, Jahr, Epoche, Thema, **Hypothese**) → Inhalt kurz → Form → Sprache → Epoche → Schluss.
2. **Form:** Strophen/Verse, Reim (aabb, abab, abba), Metrum (Jambus xX), Kadenz, Zeilenstil/Enjambement, Sonett. **Strenge Form vs. Chaos** als Satz.
3. **Stilmittel:** Metapher, Vergleich, **Personifikation**, **Verdinglichung**, **Farben**, Reihung, Anapher, Antithese, Ellipse, Neologismus, Synästhesie. **Immer: Name → Zitat (V.) → Wirkung.**
4. **Expressionismus 1910–1920:** Großstadt, Weltende, Krieg, Ich-Zerfall, Hässliches. Reihungsstil, starke Bilder, Entmenschlichung, Bürgerkritik.
5. **Präsens, „lyrisches Ich“, Verse angeben.**
